# reflect — 경험을 지식으로

## 절차
1. **되짚기** (속으로): 이번 작업에서
   - 새로 알게 된 사실/관례는? → MEMORY 후보
   - 사용자의 선호·수준·목표에 대해 새로 안 것은? → USER 후보
   - 반복될 절차이거나, 실수 후 찾은 올바른 방법은? → 스킬 후보
   - 기존 스킬이 틀렸거나 부족했나? → 스킬 패치 후보
2. **필터**: 다음 세션의 나에게 실제로 쓸모 있는가? 코드/git 기록에서 바로 알 수 있는 건 저장하지 않는다.
3. **MEMORY.md / USER.md 갱신**: 기존 항목과 합치거나 교체. 추가 후 글자 수 확인:
   `wc -m .claude/memory/*.md` — 상한(2,200 / 1,375) 초과 시 오래되거나 덜 중요한 항목부터 압축.
4. **스킬**: 후보가 있으면 `skill-forge` 스킬 절차를 따른다.
5. **저널**: `.claude/journal/$(date +%F).md`에 항목 추가 (형식은 journal/README.md).
6. 사용자에게는 한 줄로만 보고: "📝 기억함: …" (저장한 게 없으면 생략).
