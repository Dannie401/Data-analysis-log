# MEMORY — 에이전트 노트 (≤ 2,200자, 큐레이션 필수)

## 환경
- 저장소: 프로그래머스 SQL 풀이(MySQL) + 개인 프로젝트. 원격 브랜치 작업 후 push.
- 카테고리 폴더: SELECT, SUM_MAX_MIN, GROUP_BY, "  JOIN", "  SUBQUERY", projects.
- ⚠️ `SQL/  JOIN`, `SQL/  SUBQUERY`는 폴더명 앞에 공백 2칸이 있음 — 경로는 반드시 따옴표로 감쌀 것. 이름 정리는 사용자 확인 후.
- `SQL/projects/`는 루트 README가 말하는 `projects/`와 위치가 다름(미정리).

## 관례
- 파일 헤더: `-- 문제: 제목` + `-- URL`. 대안 풀이는 `/* */`로 보존.
- 카테고리 README는 `scripts/build_index.py`가 생성 — 직접 편집 금지.
